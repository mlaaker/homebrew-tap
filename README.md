# Mlaaker Tap

## How do I install these formulae?

`brew install mlaaker/tap/<formula>`

Or `brew tap mlaaker/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mlaaker/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
